# Legacy Overview Docs

This folder keeps old overview documents that are not the current design source.

These files were moved out of `docs/00-overview/` because their data flow, data model, and roadmap notes may conflict with the current block design work.

Use these files only as reference when checking old decisions or rewriting newer specs.

## Files

| File | Original role | Current status |
| --- | --- | --- |
| [data-flow.md](data-flow.md) | Old React data flow and component notes. | Legacy reference. |
| [data-model.md](data-model.md) | Old `videos.json` schema and migration notes. | Legacy reference. |
| [roadmap.md](roadmap.md) | Old phase and release order notes. | Legacy reference. |

## Rules

- Do not treat these files as the current product design source.
- If a rule or detail is still useful, rewrite it into the active design document before using it as current spec.
- Links to these files should mark them as legacy or reference material.
